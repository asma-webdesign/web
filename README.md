# Asma Web Design - Professional Freelance Website

Welcome to the *Asma Web Design* project! This is a complete, modern, and responsive website template for a freelance web designer targeting *local small businesses* such as beauty salons, clinics, restaurants, and consultants.

The website is fully functional and ready to be hosted on *GitHub Pages*.

---

## Features

- 5 pages: Home, Services, Portfolio, About, Contact  
- Modern UI/UX design with clean spacing and typography  
- Responsive layout (mobile-friendly)  
- Hero section with motion effects on text and buttons  
- Card grids with hover effects  
- Footer with contact info and social links on all pages  
- Professional stock images (replaceable in /images)  
- Google Fonts included  
- FontAwesome icons included  
- SEO-ready: Meta titles, descriptions, Open Graph tags, semantic HTML, alt text
